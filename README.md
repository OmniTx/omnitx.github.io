## 🚀 Overview

This is the repository for my professional portfolio website, hosted at [**omnitx.github.io**](https://omnitx.github.io). It features a modern, clean, and highly responsive design built with **Tailwind CSS** and **Vanilla JavaScript**, showcasing my skills in IT infrastructure, web development, and 3D modeling.

> "Managing IT infrastructure and building seamless digital experiences."

---

## ✨ Key Features

- � **Dynamic Theme Engine** - Seamlessly switch between light and dark modes with system preference detection.
- 📊 **GitHub Integration** - Real-time statistics (Repos, Stars, Forks, Followers) fetched directly via GitHub API.
- 🎨 **Modern UI/UX** - Minimalist design with glassmorphism, smooth scroll animations, and a dot-pattern background.
- 📱 **Mobile First** - Fully responsive layout optimized for all devices.
- ⏳ **Experience Timeline** - Interactive career and education history.

To run this project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/omnitx/omnitx.github.io.git
   ```
2. **Open the index file**
   Simply open `index.html` in your favorite browser. No build steps required!
   ```bash
   start index.html
   ```
