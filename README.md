# omnitx.github.io

Source for my personal site, live at [imran.mvp.bd](https://imran.mvp.bd) via GitHub Pages.

It's a single-page portfolio built with plain HTML, CSS and JavaScript. No framework, no build step.

## Features

- Light and dark theme, follows system preference on first visit and remembers your choice
- GitHub stats (repos, stars, forks, followers) pulled from the GitHub API
- Custom cursor and scroll-reveal animations on desktop
- Responsive layout, custom 404 page

## Files

```
index.html      the whole page
style.css       all styling (theme variables, layout, animations)
script.js       theme toggle, GitHub stats, custom cursor
404.html        not-found page
robots.txt      crawl rules
sitemap.xml     sitemap
CNAME           custom domain (imran.mvp.bd)
assets/         favicon and logos
```

## Running locally

Clone the repo and open `index.html` in a browser. The GitHub stats section needs an internet connection since it calls the API.

```
git clone https://github.com/omnitx/omnitx.github.io.git
```
