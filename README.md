# OmniTx Portfolio

A modern, minimalist dark-themed personal portfolio website.

🌐 **Live:** [omnitx.github.io](https://omnitx.github.io)

## Features

- 🌙 Dark mode with cyber teal accents
- ⚡ Fast & lightweight (no frameworks)
- 📱 Fully responsive design
- ✨ Smooth scroll animations
- 🎨 Modern glassmorphism effects

## Color Palette

| Usage | Color Name | Hex Code |
|-------|------------|----------|
| Primary Accent | Cyber Teal / Mint | `#00FFC8` |
| Secondary Accent | Terminal Cyan | `#2DE2C3` |
| Background (Main) | Deep Obsidian | `#0B1215` |
| Background (Panel) | Dark Petrol | `#101A1E` |
| Text (Body) | Steel Grey | `#94A3B8` |
| Borders / Grid | Dim Slate | `#1E293B` |
| Alert/Online | Neon Green | `#39FF14` |

## Tech Stack

- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## Local Development

```bash
# Clone the repository
git clone https://github.com/omnitx/omnitx.github.io.git

# Open in browser
start index.html
```
